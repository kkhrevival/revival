Kim Kardashian: Hollywood Revival Project

Everything you need to know before downloading. Please read this entire post before asking questions.

What is this project? The KKH Revival Project is a fan-led effort to bring back Kim Kardashian: Hollywood as a playable game through a custom APK. The game's original servers were shut down, and this project works to restore and rebuild as much of the experience as possible. It's a work in progress — many features are being recovered, and some may never be fully restored.

Frequently Asked Questions

Where is it available?

Android phones and tablets. You can also play on a Windows laptop or PC by downloading an Android emulator such as BlueStacks and running the APK through that.

Why isn't it available on iOS?

iOS makes sideloading apps extremely difficult by design. Apple's operating system doesn't allow you to simply install an APK file the way Android does — it requires signed IPAs, developer certificates, or jailbreaking, all of which are unreliable and constantly changing. Because of these restrictions, an iOS version is not currently feasible.

When is the next version coming out?

There is no set release date. Updates are announced when they're ready. Keep an eye on the announcements channel for the latest news.

Will I have to reinstall and wipe my data again on the next version?

Possibly. This is not yet known and will depend on the changes made. Installation instructions will be provided with each new release.

I found a bug. What do I do?

Report it in the bug reports channel in the Development server. Please include as much detail as you can — what you were doing, what happened, and any screenshots if possible.

Why isn't a certain feature working?

Many parts of the game are still incomplete. Some of the original game's assets may be permanently irrecoverable. Stay up to date with what the team finds by regularly checking the announcements channel.

Upgrading from a Previous Version

If you have any previous version of the APK installed (e.g. v1.6), follow these steps before installing the new one.

Uninstall the old APK. Press and hold the app icon (on an emulator, this may be a right-click) and select Uninstall. This will reset your data — that is intentional and necessary.

Download and install the new version from the Drive link provided in the server.

⚠ Do not skip the uninstall

If you install the new version over the old one without uninstalling first, your progress may appear to carry over — but you will encounter unfixable bugs, and your main storyline will have locks that cannot be removed.

The developers will not fix these issues, as they cannot be responsible for problems caused by not following the installation instructions.

Important Gameplay Tips

Complete Kim's house quests immediately

If you receive a quest to go and talk to Kim at her house, do it straight away. Don't let these quests pile up — having multiple active at once can cause conflicting goals and break your quest progression.

Do the main storyline first

Avoid taking on VIP quests until you've progressed through the main storyline. Doing VIP quests too early can cause conflicts. This is a legacy issue from the original Glu code and may be addressed in future versions.
